## Benchmarks

|------|-------------|----------|
| [Agents and Computer-Use Benchmarks](explainers/benchmarks/agents-and-computer-use.md) | Agent benchmarks score whether a model can finish a multi-step job in a live environment (a desktop, a website, a customer-service conversation), and the most useful single trend line is METR's "time horizon": the length of human task an AI can complete half the time. | 2026-09-30 |
| [Contamination and Saturation](explainers/benchmarks/contamination-and-saturation.md) | Benchmark scores drift upward for reasons other than capability (leaked test data, training aimed at the test, better harnesses, broken graders, selective reporting), and every public benchmark has a shelf life, so weight fresh, held-out and maintained tests above famous static ones. | 2026-09-30 |
| [Human-Preference Arenas and LLM Judges](explainers/benchmarks/human-preference-arenas.md) | Arena leaderboards rank models by which answer people prefer in blind side-by-side votes, which captures "feels better to use" better than any exam, but preference is not correctness, style sways votes, and the 2025 "Leaderboard Illusion" dispute showed how the rules of the arena shape who wins. | 2026-09-30 |
| [Knowledge and Reasoning Benchmarks](explainers/benchmarks/knowledge-and-reasoning.md) | MMLU and its successors measure how much a model knows and how well it reasons on exam-style questions, and the useful ones in 2026 are the ones that are still hard: treat any score above about 90 percent as a solved test, not a ranking. | 2026-09-30 |
| [Math and Code Benchmarks](explainers/benchmarks/math-and-code.md) | Maths and coding benchmarks are the easiest to grade automatically and the fastest to go stale, so trust the fresh, held-out and actively maintained ones (competition problems released after training, FrontierMath's holdout, versioned agent suites) over the famous static ones. | 2026-09-30 |

## Concepts

| Page | In one line | Reviewed |
|------|-------------|----------|
| [Context Windows](explainers/concepts/context-windows.md) | A context window is how many tokens a model can take in at once, and the number on the spec sheet is an upper bound on what fits, not a promise of how well the model uses it, so treat long context as a tool to test rather than a replacement for choosing what goes in. | 2026-09-30 |
| [Open vs Closed Weights](explainers/concepts/open-vs-closed-weights.md) | "Open" in AI is a spectrum, from API-only access, through downloadable weights under restrictive or permissive licences, to fully open source with code and data, so ask exactly what is released and under which licence before deciding what you can build, and read the safety debate as a disagreement about marginal risk rather than about openness in general. | 2026-09-30 |
| [Reasoning Models](explainers/concepts/reasoning-models.md) | "Reasoning" or "thinking" models are language models trained with reinforcement learning to write out a long chain of working before they answer, which trades extra tokens (time and money) for accuracy on hard problems, so you should turn the thinking up for maths, code and multi-step tasks and down for everything else. | 2026-09-30 |
| [Sampling and Decoding](explainers/concepts/sampling-and-decoding.md) | A language model only outputs a probability for every possible next token; the decoding strategy (greedy, temperature, top-k, top-p, min-p, beam search, constrained decoding) is the separate rule that turns those probabilities into actual text, and it changes the output as much as many model upgrades do. | 2026-09-30 |
| [The KV Cache](explainers/concepts/kv-cache.md) | When a language model generates text it keeps a running memory of every earlier token (the key-value, or KV, cache), and the size of that memory, not the model's weights, is often what limits context length, batch size and serving cost. | 2026-09-30 |
| [Tokenization](explainers/concepts/tokenization.md) | Language models read and write in tokens (chunks of text, usually pieces of words), not words or letters, and that one design choice explains a surprising share of their costs, limits and odd mistakes. | 2026-09-30 |
